# 第一阶段：安装与操作问题记录

## 1. Ubuntu 安装过程中硬盘识别问题

### 问题现象
安装 Ubuntu 时，安装程序无法正常识别目标硬盘或分区。

### 排查与解决
检查 BIOS 中的存储相关设置后，对 Intel VMD 相关设置进行了调整，
重新启动 Ubuntu 安装程序后，硬盘可以正常识别。

### 结果
Ubuntu 成功安装，Windows 和 Ubuntu 均可以正常启动。
